Plain PDF는 아무것도 업로드하지 않고 PDF를 읽고 고치는 앱입니다. 빠르게 열리고, 읽던 자리를 기억하며, 읽는 데 방해가 되지 않습니다. 큰 버튼, 숨겨진 제스처 없음.

읽기
• 이어서 보기 또는 한 장씩 보기
• 문서 안에서 검색, 찾은 부분은 강조 표시
• 양식을 작성하고 사본으로 저장
• 페이지에 그리기와 강조, 진짜 PDF 주석으로 저장(Android 12 이상)
• 휴대폰 음성으로 소리 내어 읽기, 인쇄, 글자 복사 또는 공유, 한 페이지만 공유
• 열려 있는 모든 문서에 항상 보이는 도구 버튼
• 페이지 바둑판, 책갈피, 페이지로 이동, 홈 화면에서 바로 이어서 읽기
• 야간, 세피아, 회색조 페이지 표시를 문서마다 기억
• 다섯 가지 앱 테마, OLED 화면을 위한 완전한 검정 포함
• 화면 켜 두기, 음량 버튼으로 페이지 넘기기, 가장자리를 밀어 밝기 조절(선택)

스캔
• 페이지를 찍으면 가장자리를 알아서 찾아 줍니다. 모서리나 변을 끌어 바로잡으세요
• 컬러, 회색조, 또는 또렷한 흑백으로 정리
• 휴대폰 안에서 글자 인식, 인터넷 불필요: 스캔에서 검색할 수 있고 글자를 복사할 수 있습니다. 8개 언어가 앱에 포함되어 있고(영어, 세르비아어는 라틴 문자와 키릴 문자 모두, 독일어, 스페인어, 프랑스어, 이탈리아어, 러시아어), 20개 언어가 설정에서 한 번 탭하면 더 추가됩니다
• 페이지를 더 찍은 뒤 바로 PDF 공유

도구, 모두 이 기기 안에서
• 서명: 서명을 한 번 그려 두고 어느 페이지에나 넣기
• 검색 가능하게 만들기: 스캔한 PDF에 인식한 글자 넣기
• 메모 쓰기: 글을 입력해 PDF로 저장
• 용량 줄이기: 안에 든 사진을 줄여 PDF를 작게
• 페이지 정리: 한 화면에서 회전, 삭제, 순서 바꾸기, 추출, 복제. 실행 취소 가능
• 여러 PDF 합치기, 문서마다 페이지 범위 선택 가능
• 페이지 범위나 N쪽마다 나누기
• 모든 페이지에 쪽 번호
• 검게 가리기: 페이지 일부를 검게 칠해 단순히 덮는 것이 아니라 실제로 지우기
• 사진, 스캔, 카메라로 사진을 PDF로
• PDF를 PNG 또는 JPEG 사진으로
• 비밀번호 추가, 변경, 해제(AES-256)

모든 작업은 먼저 임시 파일에 쓰고 확인한 뒤에야 원래 파일을 건드립니다. 어떤 것도 말없이 삭제되지 않습니다.

보관함
• 미리보기와 읽던 위치가 함께 있는 최근 문서
• 폴더 등록, 즐겨찾기, 검색과 정렬
• 옮겨졌거나 사라진 파일은 버리지 않고 표시해 두며, 다시 찾기 버튼을 제공합니다
• 홈 화면 위젯과 스캔, 열기, 이어서 읽기 바로가기

영어, 세르비아어, 독일어, 스페인어, 프랑스어, 포르투갈어, 러시아어, 아랍어, 힌디어, 중국어, 일본어, 한국어 등 17개 언어 지원.

광고 없음. 분석 없음. 계정 없음. 네트워크 접근이 전혀 없음: 앱에 인터넷 권한 자체가 없습니다. 읽기와 편집 기능은 모두 무료이며, 선택 사항인 후원자 구매는 강조 색상과 아이콘만 열어 줍니다.
